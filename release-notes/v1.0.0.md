First public version of the DORA Dashboard.

- Five DORA metrics for any public GitHub repository, explained in plain language:
  deployment frequency, change lead time, and three clearly labelled proxies (change
  failure rate, failed deployment recovery time, rework rate).
- Runs entirely in the browser. An optional token is kept in memory only.
- A clear message for each error case: repository not found, private repository, no
  releases, rate limit reached, no network.
- Tested against a known-answer sandbox ([GonzaSSH/dora-sandbox](https://github.com/GonzaSSH/dora-sandbox),
  [EXPECTED.md](https://github.com/GonzaSSH/dora-dashboard/blob/main/sandbox/EXPECTED.md)),
  with unit, browser and live checks in CI.

Live: https://gonzassh.github.io/dora-dashboard/
