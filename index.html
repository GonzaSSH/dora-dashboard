DORA Dashboard

Type a public GitHub repository and see the five DORA software delivery metrics, explained in plain language.

Why a token?

Without a token, GitHub allows 60 requests per hour from your internet connection. That is enough for most repositories; for very active ones the app measures a sample and tells you so. A token raises the limit to 5,000 per hour.

To create one: on GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token, under "Repository access" choose "Public repositories", generate it and paste it here.

Your token stays in this browser tab only. It is sent only to GitHub, never saved, and is forgotten when you close or reload the page.

What the five metrics mean

"Strong" and "weak" are a rough guide, given only for the two directly measured metrics. The three proxy metrics are estimates, so they get no rating. Compare a team with its own past, not with other teams.
