# dora-sandbox

A fake project with a scripted git history and **known DORA metric answers**.
It is used to test [dora-dashboard](https://github.com/GonzaSSH/dora-dashboard).

- Every commit and tag has a fixed, backdated date. No GitHub Releases are used,
  because GitHub sets release dates itself and they cannot be backdated.
- The history is generated by
  [`sandbox/build-sandbox.sh`](https://github.com/GonzaSSH/dora-dashboard/blob/main/sandbox/build-sandbox.sh)
  and is overwritten each time that script runs.
- The expected metric values, with the arithmetic shown, are in
  [`sandbox/EXPECTED.md`](https://github.com/GonzaSSH/dora-dashboard/blob/main/sandbox/EXPECTED.md).

Do not open pull requests here; change the script instead.
